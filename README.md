# КРОССОВКИ БЕЛАРУСЬ

Сайт-визитка Telegram-бутика обуви из Витебска. Матовый чёрный, крупная техно-типографика, тонкие белые линии и кислотный акцент. Без градиентов и сборщиков.

## Запуск

```bash
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## Что внутри

- Главный экран с крупной типографикой и редакционным фото.
- Контурная типографика в hero и футере — без растровых эффектов и градиентов.
- Полоса сервиса: доставка, отправка, размер, оплата.
- Интерактивная подборка из четырёх моделей: вкладки, смена фото и карточки товара.
- Раздел «Подход» с полноэкранным изображением.
- Форма персонального запроса: собирает модель, размер и город в готовое сообщение Telegram.
- Прозрачный информационный блок о репликах, наличии, доставке и размерах.
- Кастомный курсор-кроссовок с анимацией нажатия на устройствах с мышью.
- Мобильное меню, адаптив, локальные шрифты, favicon, Apple Touch Icon и OG-превью.

## Что менять перед публикацией

1. Заменить демо-фото в `assets/` на реальные фотографии товара. Сохранить имена файлов или обновить пути в `index.html`.
2. Проверить цены `от 75 BYN`, количество подписчиков `4 400+`, публикации `3 700+` и тексты.
3. Проверить наличие моделей в подборке и ссылки на Telegram.
4. При необходимости отключить кастомный курсор: удалить блок `Custom sneaker cursor` в `script.js`.
5. Проверить, что для всех пар указана корректная информация.

## GitHub Pages

Публичный репозиторий: `https://github.com/AntonyWes/krossy`.

После пуша:

1. Открыть **Settings → Pages**.
2. Source: **Deploy from a branch**.
3. Branch: **main**, folder: **/(root)**.
4. Нажать **Save**.

Сайт будет доступен по адресу `https://antonywes.github.io/krossy/`. Все пути в проекте относительные, поэтому он корректно работает из подпапки. Файл `.nojekyll` уже добавлен, чтобы GitHub не прогонял сайт через Jekyll.

## Деплой

Папка является готовым статическим сайтом. Можно загрузить содержимое на Netlify, Vercel, Cloudflare Pages или GitHub Pages. Точка входа — `index.html`.
